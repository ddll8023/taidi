# 上市公司财报智能问数助手 项目结构文档

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 后端框架 | FastAPI | 用于构建 RESTful API 服务 |
| 后端运行时 | Uvicorn | ASGI 服务器，用于运行 FastAPI 应用 |
| ORM | SQLAlchemy | 用于数据库模型定义与 ORM 操作 |
| 数据库驱动 | PyMySQL | 用于连接 MySQL 数据库 |
| 数据库 | MySQL | 关系型数据库，存储业务数据 |
| 向量数据库 | Milvus (PyMilvus) | 用于存储和检索文本向量嵌入 |
| 数据校验 | Pydantic + pydantic-settings | 用于请求/响应模型校验与配置管理 |
| LLM 调用 | LangChain + DashScope + Anthropic | 用于大模型调用、文本生成与向量化 |
| 认证安全 | PyJWT + bcrypt + cryptography | 用于 JWT 认证、密码加密与安全处理 |
| 文件处理 | pypdf + docx2txt + openpyxl + mutagen | 用于 PDF、Word、Excel 及音频文件的解析 |
| 云存储 | oss2 (阿里云 OSS) | 用于文件云存储 |
| 可视化 | Matplotlib | 用于生成数据图表 |
| 包管理 | uv | Python 包管理与虚拟环境管理 |
| 前端框架 | Vue 3 | 用于构建用户界面 |
| 前端路由 | Vue Router | 用于前端页面路由管理 |
| 状态管理 | Pinia | 用于全局状态管理 |
| HTTP 客户端 | Axios | 用于发起后端 API 请求 |
| CSS 框架 | Tailwind CSS | 用于原子化 CSS 样式开发 |
| 构建工具 | Vite | 用于前端开发服务器与生产构建 |
| Markdown 渲染 | marked + DOMPurify | 用于 Markdown 内容渲染与 XSS 防护 |
| 图标库 | Font Awesome | 用于界面图标展示 |

### 依赖配置文件

| 文件 | 说明 |
|------|------|
| backend/requirements.txt | 后端 Python 依赖清单，包含 FastAPI、SQLAlchemy、LangChain、PyMilvus 等 |
| backend/pyproject.toml | 后端项目元信息与 Python >=3.12 版本要求 |
| backend/uv.lock | uv 生成的依赖锁定文件，固定依赖版本 |
| backend/.python-version | 声明后端开发环境 Python 版本为 3.12 |
| frontend/package.json | 前端依赖与脚本配置，包含 Vue 3、Pinia、Axios、Tailwind CSS 等 |
| frontend/package-lock.json | npm 依赖锁定文件 |
| frontend/vite.config.js | Vite 构建配置，开发服务器端口 7388，代理 /api 至后端 7389 |
| frontend/postcss.config.js | PostCSS 配置，启用 Tailwind CSS 与 Autoprefixer 插件 |
| frontend/tailwind.config.js | Tailwind CSS 主题配置，自定义颜色、阴影、动画与字体 |
| frontend/jsconfig.json | 前端路径别名配置，@ 指向 src 目录 |

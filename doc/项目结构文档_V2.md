# 财报智能问数助手 V2 项目结构文档

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 后端框架 | FastAPI + Uvicorn | 构建高性能 REST API 服务 |
| 数据库 | MySQL (PyMySQL) | 关系型数据持久化存储 |
| ORM | SQLAlchemy | 数据库模型定义与查询操作 |
| 数据校验 | Pydantic / Pydantic Settings | 请求/响应 Schema 定义与环境变量管理 |
| 认证授权 | PyJWT + bcrypt + cryptography | JWT 令牌认证、密码哈希与安全处理 |
| LLM 调用 | LangChain + DashScope + OpenAI + Anthropic | 多模型 AI 调用，支持 Embedding 和 Chat |
| 向量数据库 | Chroma | 存储和检索文本向量 |
| 文件解析 | docx2txt + PyPDF + openpyxl + mutagen + langchain-community | 解析 Word、PDF、Excel、音频元数据；PDF 文本提取（PyPDFLoader） |
| 对象存储 | Alibaba Cloud OSS (oss2) | 文件上传至阿里云 OSS |
| 数据处理 | Pandas + Matplotlib | 数据分析与可视化 |
| 前端框架 | Vue 3 | 渐进式前端 UI 框架 |
| 路由 | Vue Router 4 | SPA 路由管理 |
| 状态管理 | Pinia | 全局状态管理 |
| HTTP 客户端 | Axios | 前端 HTTP 请求封装 |
| CSS 框架 | Tailwind CSS | 原子化 CSS 样式 |
| 图标 | Font Awesome (vue-fontawesome) | 界面图标展示 |
| Markdown | marked + DOMPurify | Markdown 渲染与 XSS 防护 |
| 构建工具 | Vite | 前端开发服务器与打包构建（端口 7388，代理 7389） |
| 包管理 | uv | Python 依赖管理与虚拟环境 |
| 运行时 | Python 3.12 | 后端运行环境 |

### 依赖配置文件

| 文件 | 说明 |
|------|------|
| backendV2/pyproject.toml | 后端项目元数据，Python >= 3.12，通过 uv 管理依赖 |
| backendV2/requirements.txt | 后端 Pip 依赖清单（FastAPI、SQLAlchemy、LangChain 等 27 个包） |
| backendV2/.python-version | Python 版本锁定为 3.12 |
| frontendV2/package.json | 前端依赖声明，含 Vue 3、Pinia、Vue Router、Tailwind CSS、Axios 等 |
| frontendV2/package-lock.json | npm 依赖锁定文件 |
